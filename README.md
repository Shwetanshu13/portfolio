# Shwetanshu Sinha - Personal Portfolio

Welcome to the source code for my personal portfolio website! This project showcases my skills, projects, open-source contributions, and blog posts, all wrapped in a sleek, modern, glassmorphic design.

## 🚀 Features

- **Dynamic Theming**: Seamless Light and Dark mode support with persistent state.
- **Unified Activity Heatmap**: A custom integration that aggregates my coding activity across GitHub, LeetCode, and Codeforces into a single, beautiful timeline (powered by my NPM packages `@unified-heatmap/core` and `@unified-heatmap/react`).
- **Glassmorphic UI**: A premium, "Sunset Orange" aesthetic featuring subtle ambient glowing orbs, backdrop blurs, and crisp borders.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Live Data**: Fetches latest blog posts from Hashnode and activity statistics dynamically.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: JavaScript/React
- **Icons**: Custom SVGs
- **Deployment**: [Vercel](https://vercel.com/) (Recommended)

## 💻 Running Locally

To run this project on your local machine, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd portfolio-website
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   # or npm install / yarn install
   ```

3. **Start the development server**:
   ```bash
   pnpm run dev
   # or npm run dev / yarn dev
   ```

4. **View the application**:
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
